Wine Intelligence Harness

A personal tool for retaining and reviewing the owner's wine-cellar exports.

The tool retrieves the owner's native CellarTracker CSV export, checks its structure and current holdings, and retains the unchanged file and a verification receipt in the owner's private Google Drive. Hosted GitHub Actions runs allow the retention process to execute without an available personal computer.

The integration is undergoing qualification. These public pages describe the app and its data practices; they do not provide access to cellar records, credentials or the private implementation repository. There is no public registration or sign-in service on this site.

Google access

The app requests https://www.googleapis.com/auth/drive.file to create and read its retained files. It checks the authorized Google account's email to confirm the expected owner.
