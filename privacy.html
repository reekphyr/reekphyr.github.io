Privacy policy

Wine Intelligence Harness is a personal-use tool operated by its owner.

Data accessed and used

The tool uses the authorized Google account's email to confirm the expected owner. With the drive.file permission, it creates and reads app-accessible Drive files and checks their metadata, ownership, parent folder and sharing information. Access is used to retain cellar CSV exports, create verification receipts and verify downloaded file contents.

Cellar exports can contain wine identities, bottle status, storage locations, purchase details, prices and personal notes. Original exports include consumed-bottle history. The tool uses a separately authorized CellarTracker session to obtain the owner's exports.

Processing and storage

Processing takes place on GitHub-hosted runners. OAuth credentials and the CellarTracker session are stored in the owner's private GitHub repository secrets. Retained exports and receipts are stored in the owner's private Google Drive. Execution logs contain validation results and file identifiers; credentials and complete inventories are not intended to be printed in those logs.

Google and GitHub process data as providers of these services under their own terms and privacy policies. The owner may separately choose to retrieve records through connected analysis tools, including ChatGPT, for personal cellar analysis. That processing is governed by the selected service's settings and terms.

Sharing and public information

The app does not publish cellar exports on this website, sell Google user data, use it for advertising or use it to train generalized AI models. This website contains only informational pages. Hosting providers may process standard request logs; these pages add no analytics scripts, tracking pixels or sign-in forms.

Retention and deletion

The owner controls retained Drive files and can delete them. Previous exports remain until the owner deletes them; this integration currently has no automatic deletion policy. Credentials remain in repository secrets until the owner replaces or removes them. Access can be revoked through the Google account's third-party app access settings. Revocation stops future authorized access but does not itself delete previously retained files.

Contact and changes

Use the support email displayed on the Google OAuth consent screen for questions, access requests or deletion requests. Do not post credentials or cellar records in public GitHub issues. This policy will be updated if the integration's data practices change.
